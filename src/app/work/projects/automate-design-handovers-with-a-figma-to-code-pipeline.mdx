## Aperçu

Invinta est une application web conçue pour gérer des processus métier et des données utilisateur à travers un backend robuste. Le projet m’a permis de mettre en pratique la conception d’une application complète, depuis la modélisation des données jusqu’à la mise en ligne.

## Ce que j’ai construit

- **Back-end Django** pour la gestion de l’application.
- **API et logique métier** pour les fonctionnalités clés.
- **Interface web** avec HTML, CSS et JavaScript.
- **Gestion des données et stockage** avec base de données relationnelle.
- **Intégration Cloudinary** pour les médias et fichiers associés.

## Technologies utilisées

- **Python**
- **Django**
- **Django REST Framework**
- **HTML / CSS / JavaScript**
- **Base de données SQL**
- **Cloudinary**

## Défi et apprentissage

Le projet a été une bonne mise en pratique de la création d’une application web cohérente, utile et exploitable. J’ai appris à structurer un back-end, à organiser les fonctionnalités métier et à concevoir une application en gardant un bon équilibre entre performance, lisibilité et maintenance.

## Résultat

Invinta a été développé puis déployé en ligne, ce qui m’a permis d’approfondir ma pratique du développement web et de mieux comprendre le cycle complet de création d’une application : conception, développement, déploiement et amélioration continue.
